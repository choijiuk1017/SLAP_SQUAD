# SLAP SQUAD

Unity로 개발한 3D PvP 멀티플레이 게임입니다.  
서버 프로그래머와 협업하여 클라이언트 게임플레이 및 네트워크 시스템을 담당했습니다.

| 개발 환경 | Unity, C# |

## 주요 구현

- 캐릭터 조작, 전투 및 게임 진행을 포함한 클라이언트 게임플레이 로직
- 로그인, 로비, 방 입장, 게임 진행 등 서버 상태와 연동되는 게임 흐름 및 UI
- 서버와의 데이터 교환을 위한 패킷 송수신 기반 클라이언트 네트워크 시스템
- 캐릭터별 무기 특성에 따른 공격 로직과 공격 패킷 처리
- 원격 플레이어의 이동 및 공격 동기화

## 메시지 기반 네트워크 처리 구조

- 서버에서 수신한 메시지를 Command 단위로 파싱하고 등록된 Handler로 분배
- `IMessageHandler` 인터페이스를 기반으로 기능별 Receiver의 메시지 구독 및 해제
- 네트워크 처리와 게임 로직을 분리하여 새로운 메시지와 기능을 확장하기 쉬운 구조로 구성

## 트러블슈팅

### 공격 애니메이션과 타격 판정 불일치

클라이언트별 공격 처리 시점 차이로 공격 애니메이션과 실제 타격 판정이 일치하지 않는 문제가 발생했습니다.

수신한 공격 정보를 `PendingAttack`에 저장하고 `Animation Event` 시점에 판정을 실행하도록 변경했습니다. 또한 이벤트가 누락된 경우 일정 시간 후 판정을 실행하는 Fallback 로직을 추가했습니다.

이를 통해 공격 판정 기준을 Animation Event로 통일하고, 이벤트 누락 상황에서도 공격 처리가 유실되지 않도록 개선했습니다.
